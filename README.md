# High-Performance-In-Memory-Key-Value-Store
A high-performance, Redis-inspired C++ in-memory key-value store implementing LRU and LFU cache eviction, O(1) cache operations, configurable capacity, TTL-based expiration, and thread-safe sharded caching. Includes Token Bucket and Sliding Window rate limiters, multithreaded performance benchmarking, and GoogleTest-based unit testing.
